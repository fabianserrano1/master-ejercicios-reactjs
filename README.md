# Mis proyectos con React

Repositorio creado durante el Máster de Full Stack Web Development para desarrollar y practicar aplicaciones web con React.

## 🌐 Página principal

Puedes acceder a la página principal desde la que se puede navegar entre los ejercicios y el proyecto final.

[Ver mis proyectos publicados](https://fabianserrano1.github.io/master-ejercicios-reactjs/)

## 📚 Proyectos incluidos

### 1. Entrega de ejercicios 1 - React

Colección de nueve ejercicios prácticos para trabajar distintos conceptos de React.

1. Cambiador de color de fondo.
2. Contador de clics.
3. Lista dinámica.
4. Filtro de búsqueda en tiempo real.
5. Calculadora sencilla.
6. Temporizador con inicio, pausa y reinicio.
7. Generador de contraseñas aleatorias.
8. Contador de palabras y caracteres.
9. Lista de tareas con LocalStorage.

[Ver los ejercicios publicados](https://fabianserrano1.github.io/master-ejercicios-reactjs/ejercicio-1/)

### 2. Proyecto final - CatGallery

Aplicación web que muestra imágenes de gatos utilizando The Cat API.

Funcionalidades principales:

- Carga de imágenes desde una API REST.
- Galería de imágenes en una cuadrícula adaptable.
- Añadir y eliminar imágenes favoritas.
- Guardar los favoritos en LocalStorage.
- Cargar más imágenes.

Tecnologías principales: React, TypeScript, SCSS y Vite.

[Visitar CatGallery](https://fabianserrano1.github.io/master-ejercicios-reactjs/proyecto-final/)

## 💻 Ejecución en local

Clona el repositorio:

    git clone https://github.com/fabianserrano1/master-ejercicios-reactjs.git

Entra en la carpeta del repositorio:

    cd master-ejercicios-reactjs

Para ejecutar los ejercicios:

    cd ejercicio-1
    npm install
    npm run dev

Para ejecutar CatGallery, vuelve a la raíz del repositorio y entra en su carpeta:

    cd ../proyecto-final
    npm install
    npm run dev

## 🚀 Publicación

Los proyectos están publicados mediante GitHub Pages. La compilación y publicación se realizan automáticamente con GitHub Actions al enviar cambios a la rama `main`.
